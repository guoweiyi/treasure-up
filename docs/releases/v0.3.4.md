# Treasure Up v0.3.4

本版完成项目提供的蓝发角色 logo 在网页、可安装 Web 应用、浏览器选片助手和 iOS / iPadOS 客户端中的统一适配，并补齐窄屏布局、助手配色及发版重跑处理。服务版本为 **0.3.4 preview**；原生客户端独立保持 **0.4.3（build 4）**，浏览器选片助手保持 **1.3.0**。

## 品牌覆盖与补丁内容

- 网页导航、登录、管理侧栏、页脚和首次空库使用统一品牌组件，保留自定义站点名称，并适配窄屏、深色容器、键盘与屏幕阅读器。
- 保留提供的原图和透明母图，生成完整 logo 与无文字角色资源；标签页 favicon、Windows 浏览器图标、Apple 主屏幕、PWA 和原生 App 分别使用所需尺寸。Android maskable 图标采用独立安全区资源，原生 1024px AppIcon 保持不透明 RGB。
- 离线页展示品牌 logo，并补齐 320px 窄屏布局；联网后更新公共品牌缓存并清理旧缓存。Service Worker 只保存公共离线页与品牌资源，会话、API 响应及媒体不写入离线缓存。
- 选片助手内嵌品牌图片，首次连接前也能展示；浮动入口、选片面板、连接设置、提交操作及辅助文字统一使用蓝灰配色，成功、警告与错误提示保持各自语义颜色。
- 原生连接、登录、启动、iPad 侧栏与关于页使用统一标志，关于页从 Bundle 读取客户端实际版本。
- 发版 CI 保留镜像、打包、Compose 与代理的必要验证，并校验 PNG 尺寸、透明通道、内容摘要、Web / 原生资源一致性、PWA 图标用途和公共缓存范围。
- iOS 回归结果按设备与运行次数分别保存，避免重跑时诊断附件重名；模拟器包保留固定附件名，仅在对应测试与归档成功后替换，支持失败任务重跑。

相对于上一公开版本 0.3.2，本版提供以上完整品牌适配，并包含采集凭据续期、任务恢复及原生播放修复；同时补齐 320px 窄屏布局、统一选片助手样式和发版安全重跑处理。

## 下载与升级

使用 `treasure-up-v0.3.4-docker.zip` 部署预构建的 amd64 / arm64 镜像；在解压目录运行 `python deploy/start.py --prebuilt`，资源有限时追加 `--light`。部署包固定本次验证过的镜像摘要，preview 通道不会更新 latest。

从上一公开版本 0.3.2 升级时，保留原 `.env`、存储密钥、媒体和 Docker 数据卷，在新部署包目录沿用原配置执行上述启动命令；不要运行 `docker compose down -v`。本次品牌补丁没有新增数据库迁移，启动入口仍执行仓库已有的迁移。网页首次联网后替换旧公共缓存；已安装的主屏幕图标可能由系统继续缓存，若未刷新可移除旧快捷方式并重新添加。选片助手可从本版附件或后台“浏览器采集”重新安装，以获取完整蓝灰配色。

`treasure-up-v0.3.4-ios-simulator-ad-hoc.zip` 仅供 iOS 模拟器，不能安装到真机，也不是 App Store 发布包。原生版本保持 0.4.3（build 4）；真机安装需使用自己的 Apple 开发签名构建。源码与发布附件均附 SHA-256 校验记录。

发布流水线必须完成前后端验证、iPhone / iPad 离线回归、双架构镜像构建、摘要校验及打包后才公开 GitHub Release。
