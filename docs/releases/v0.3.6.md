# Treasure Up v0.3.6

安装入口改为 `yunyunjuan/treasure-up`，程序入口、运行用户和配置卷都已内置。新安装只需运行：

```sh
docker run --rm -it -v /var/run/docker.sock:/var/run/docker.sock yunyunjuan/treasure-up:0.3.6
```

完成后打开 <http://localhost:8788>，使用终端显示的管理员账密登录。安装容器退出后，服务会继续运行。

已有 v0.3.5 安装器部署可以直接运行这条命令升级，原配置与数据卷会自动复用。更早的 Compose 部署仍需导入原 `.env`，操作见安装文档。

Docker socket 仅供安装容器创建服务使用。日常运行的服务不挂载它。

附件包含 iPhone / iPad 真机 IPA 和 `IOS-INSTALL.md` 自签名说明。
