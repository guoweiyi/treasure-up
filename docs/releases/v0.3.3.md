# Treasure Up v0.3.3

本版将项目提供的蓝发角色 logo 统一适配到网页、可安装 Web 应用、浏览器选片助手和 iOS / iPadOS 客户端。服务版本为 **0.3.3 preview**；附件中的原生客户端独立更新为 **0.4.3（build 4）**。

- 网页导航、登录、管理侧栏、页脚和首次空库采用统一品牌组件；保留自定义站点名称，适配窄屏、深色容器、键盘与屏幕阅读器。
- 提供完整 logo 和无文字角色两套透明资源；标签页、Windows 浏览器 favicon、Apple 主屏幕、PWA 和原生 App 使用各自所需尺寸。Android 遮罩图标使用独立安全区版本，原生图标保持不透明。
- 离线页展示新 logo；Service Worker 更新公共资源缓存并清理旧版缓存，会话、API 响应和媒体继续直接访问服务端。
- 浏览器选片助手升级到 1.3.0，内嵌品牌图片并统一蓝色外观；首次连接前即可展示，无需向私人服务请求 logo。
- 原生连接、登录、启动、iPad 侧栏和关于页统一使用新标志，关于页从 Bundle 读取真实版本。
- 修复仓库清理后发版 CI 引用缺失测试的问题，仅恢复镜像、发版、Compose 和代理的必要验证；新增跨平台品牌资源校验。

## 下载与升级

使用 `treasure-up-v0.3.3-docker.zip` 部署预构建的 amd64 / arm64 镜像；在解压目录运行 `python deploy/start.py --prebuilt`，资源有限时追加 `--light`。镜像摘要随包固定，preview 通道不会更新 latest。

升级时保留原 `.env`、存储密钥和 Docker 数据卷；不要运行 `docker compose down -v`。本版没有新增数据库迁移。网页首次联网后会替换旧公共缓存；已安装的主屏幕图标可能由系统继续缓存，若未刷新可移除旧快捷方式并重新添加。

`treasure-up-v0.3.3-ios-simulator-ad-hoc.zip` 仅供 iOS 模拟器，不能安装到真机，也不是 App Store 发布包。真机安装需使用自己的 Apple 开发签名构建。源码与附件均附 SHA-256 校验记录。

发布流水线必须完成前后端验证、iPhone / iPad 离线回归、双架构镜像构建、摘要校验及打包后才公开 Release。本版同时包含上一公开版本之后 main 分支已有的采集凭据续期、任务恢复与原生播放修复。
