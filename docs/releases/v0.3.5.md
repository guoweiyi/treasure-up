# Treasure Up v0.3.5

这版把安装和发版流程重新整理了一遍。只需准备好 Docker，就能启动网页、数据库和采集服务。

- 镜像改为发布到 Docker Hub，支持 amd64 和 arm64。
- 安装器自动创建配置、生成管理员账密，并启动服务；升级时保留已有配置和数据卷。
- iOS 发版增加可自行签名的真机 IPA，支持 iPhone 和 iPad。
- 修复 iPhone 退出全屏后场景仍停留在横屏的问题。
- 整理安装、反向代理、升级和开发文档，移除过时的部署与发布入口。

## Docker 安装

```sh
docker run --rm -it --pull always --user 0 -v /var/run/docker.sock:/var/run/docker.sock -v treasure-up-config:/config docker.io/yunyunjuan/treasure-up-backend:0.3.5 python /app/install.py
```

安装完成后打开 <http://localhost:8788>，使用终端显示的管理员账密登录。默认使用轻量模式，命令末尾添加 `--mode full` 可启用独立的下载和媒体处理进程。局域网、NAS 和 HTTPS 部署方法见项目安装文档。

安装器通过 Docker socket 创建服务，完成后自动退出；运行中的业务容器不会挂载该 socket。

## iPhone / iPad

下载附件 `treasure-up-v0.3.5-ios-unsigned.ipa`，按照 `IOS-INSTALL.md` 自行签名后安装。IPA 未附带开发者签名，不能直接点击安装。进入 App 后填写自己的服务器地址并登录。

## 已有部署升级

先备份数据库、配置和媒体文件。安装器配置保存在 `treasure-up-config` 卷中，业务数据沿用 `treasure-up` 项目的数据卷，不要删除这些卷。旧 Compose 用户请按照安装文档迁移原 `.env` 后再使用安装器，避免生成不同的数据库密码或加密密钥。
