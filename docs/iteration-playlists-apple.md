# 片单、采集确认与 Apple 播放迭代

开发基线：`a9ec511`。本轮更新本机 Docker 预览，不新增公开 Release，也未重新签名 iOS 应用。原有归档保留，数据库迁移前已在本机忽略目录保存 PostgreSQL 快照。

## 使用变化

- **浏览器选片助手 1.1.0**：后台「浏览器采集」提供安装、连接和故障指引；B 站右下角有明确入口。修复动态卡片复用导致选错 BV、验证失败覆盖已有连接、代理返回 HTML 时错误难懂等问题。已有安装需要从后台更新脚本。见[安装说明](userscript-guide.md)。
- **播放页面**：桌面播放队列回到右栏，单 P 不显示多余选集；手机保留自定义控制栏和底部设置面板。侧栏及 UP 列表简介限制为 60 字；UP 详情简介折叠，允许主动展开。减少圆角，统一字体、边框和间距。
- **我的片单**：原星标迁入「稍后看」，兼容原星标接口；可以建立自己的片单、写备注、标记已看、筛选和移动视频，从片单进入连续播放。个人片单与 B 站采集来源分开；移除成员、删除片单不会删除视频归档。每个用户最多 100 个自定义片单。
- **充电视频**：来源配置增加默认关闭的保存选项。扫描识别后显示待确认数量，确认「保存全部可访问的充电视频」才按来源授权保存。已识别的充电视频不受普通「最近 N 个 / 从现在开始」首次范围限制。不会扩大账号在 B 站的访问权限，不自动恢复已暂停或取消的任务。
- **iPhone / iPad**：底部导航、账户菜单、自定义播放设置、触控目标及安全区；连接页优化输入和按钮尺寸。原生 HLS 按真实媒体能力选择，不再只识别 Safari 用户代理；仍使用项目自己的网页控制界面。

## 杜比原档

实际样片验证发现：镜像里的 FFmpeg 7.1.5 在无损合并时保留 EC-3 音频包，但丢失 MP4 `dec3` 中的 JOC 标记。现在以原始音轨为依据，对**尚未发布的新合并文件及 HLS 初始化文件**校验和恢复标记；限定解析大小、偏移及文件布局，遇到不一致则失败，不猜测声道或复杂度。

音视频压缩包摘要验证保持一致。AAC 兼容副本仍独立存在，不替换杜比原档。前端区分原档信息、设备报告的解码能力和未验证的实际空间音频输出。详细依据和限制见 [Atmos 保存说明](../backend/app/playback/ATMOS.md)与 [iOS 播放说明](../frontend/src/player/IOS_NOTES.md)。

**这不是旧文件修复迁移。** 以前已经丢失 JOC 标记的文件不会自动恢复；普通刷新可能复用旧文件。需要原始音轨和独立恢复流程，当前没有一键修复按钮，不应删除原档来强制重采。

## 本轮审查与修复

复核账号鉴权、请求边界、个人列表隔离、来源同意、任务恢复、媒体封装、临时记录及前端异步交互；以前的审计结果见[代码审计记录](code-review-2026-10-04.md)。

| 问题 | 处理 |
| --- | --- |
| 只检查 Content-Length，可被分块请求绕过大小限制 | ASGI 层按实际读取字节限制为 1,000,000，再交给 JSON 解析 |
| 采集账号已过期，关联选片令牌仍能提交 | 验证与提交均拒绝；拒绝不消耗任务额度 |
| 播放会话、登录会话及节点探测记录持续累积 | 定时分批清理过期数据；每表每次最多 1,000 条，跳过被锁记录，保留有效会话 |
| 个人片单分页与并发移除交错，可能返回 500 | 在同一查询快照取得视频及其成员记录 |
| 撤回充电同意后，已完成媒体被误标为待确认 | 区分真正完成与因等待同意而结束的任务；复用已完成媒体，新下载仍重新验证 |
| 快速切换视频或片单，迟到响应可能显示旧内容或编辑错误对象 | 固定编辑目标、使过期请求失效、写入期间限制关闭，失败可重试 |
| 收藏页未传 enabled 时被 Vue 布尔转换误报暂停 | 未知状态显式保持 undefined，不冒充关闭状态 |

后端 Docker 镜像约由 302 MB 降至 279 MB，减少约 7.4%。通过避免重复 chown 层及安装时的字节码产物实现；没有删除音视频处理、备份或鉴权能力，没有增加模型或常驻服务。

## 验证及边界

- 最终后端镜像全套回归 **496 通过、2 跳过**，使用真实 PostgreSQL 的随机隔离数据库，覆盖迁移、并发、权限、备份与媒体处理。两项跳过需要另行提供杜比私有样片；实际样片专项单独执行，不与全套数字相加。
- 前端 80 项回归、类型检查与生产构建通过；原生连接页 7 项、部署及流水线 109 项通过。杜比样片专项 44 项通过，包括音视频包摘要、JOC、异常容器、取消和源文件不变性。
- 本机浏览器完成：片单创建、加入、已看、备注、移动及列表播放；桌面右侧列表；390px 与 1024px 无横向溢出；后台充电开关和安装指引。只为验收创建的片单与成员已清理，5 个原有视频均保留。
- 部署冒烟验证：游客浏览及媒体 Range 206、播放会话归属隔离、匿名管理操作拒绝、脚本静态响应与匿名提交拒绝。没有为验证提交真实下载任务或颁发采集令牌。
- 对用户指定充电样本只读核验：UP 列表当前第一页能识别的 7 个充电条目均被识别；详情确认账号有完整访问权限。其他 UP 若不在列表提供充电标记、且视频不在普通采集范围，仍可能未被发现，不宣称覆盖平台所有变化。
- Tampermonkey 的真实安装、权限与完整令牌保存流程尚需用户浏览器验证；脚本接口隔离和失败保留选择已由自动测试及 RAM 模拟页面覆盖。
- **尚未完成真实 iPhone / iPad / macOS 的解码与空间音频输出验收。** Windows 浏览器尺寸模拟不能证明 iOS 27 硬件兼容、旋转安全区或 Atmos 音响输出；本轮未重新生成签名 IPA。
- 未新增依赖；沿用同日公告审计中 Linux / BSD GTK 传递链的 `glib` 与 `proc-macro-error` 两项已记录限制。未做容器系统包完整 CVE 扫描，不宣称不存在其他漏洞。
