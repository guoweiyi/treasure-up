## 已实际验证

- Windows 本地单元 / API 测试，以及 Linux Docker 内真实 PostgreSQL、Redis、Nginx、FFmpeg 运行。
- 登录权限、Origin / CSRF、阅读者限制、私有资产 Range、来源更新不覆盖人工标注、历史昵称检索、评论树。
- 从既有技术实验导入一个真实 H.264/AAC 视频及 427 条弹幕；新站浏览器实际播放，进度恢复和弹幕显示正常。未重新下载源站视频，样本和用户数据不上传仓库。
- 真实 PostgreSQL 导出快照：在快照后并发新增的资产不会进入该次数据库 dump 或资产清单。
- 删除隔离测试源库并隔离原媒体后，仅凭加密备份恢复到独立空库；SHA-256 一致，恢复视频可完整 FFmpeg 解码。
- 并发任务领取只有一个赢家，过期 Worker 提交被拒绝；迁移后的读回和失效位置回退。
- 真实 FFmpeg 合成 HEVC/AAC 短片转 H.264/AAC，保留原档字节并完整解码。

以上恢复测试只创建和清理随机 `treasure_test_*` 数据库与独立 scratch 目录，不破坏业务数据。本机最终测试为 **101 通过、5 跳过**（Windows 缺少系统 FFmpeg、符号链接权限和显式 PG 测试条件）；最终 Linux 容器开启真实 PG 验证后为 **107 项全部通过**。前端类型检查及生产构建通过；远程 CI 状态以 GitHub 为准。

## 尚待实测或后续实现

| 项目 | 具体边界 |
| --- | --- |
| 新站在线采集 | 来源适配器已通过脱敏夹具、失败分支和断点测试；本轮没有用真实 Cookie 新建采集任务。会员清晰度、实际评论游标、风控变化仍需小样本实测 |
| S3 / OSS | SDK 适配和模拟协议测试已完成；尚未配置真实桶，公网 CORS、签名续期、分片中断恢复、费用均未宣告验收 |
| 云端备份仓库 | 当前仅目录 / 挂载 NAS；原生 S3 / OSS 备份目的地尚未实现。默认本机命名卷不是异机容灾 |
| HDR / 广色域 | 原档保留并记录色彩标签；不生成未经验证的 SDR 转换副本，明确提示不支持 |
| 弹幕高级模式 | 保存来源数据，首版渲染滚动 / 顶部 / 底部；不执行源站代码弹幕，也未复刻高级定位、蒙版防挡人 |
| 采集完整性 | 仅可访问范围；平台已删除、隐藏、审核中内容及接口未提供的历史版本无法承诺恢复 |
| 历史与管理 | 昵称、头像和评论版本有快照；尚无所有视频元数据的逐版本比较 / 一键回滚；审计日志不是完整编辑历史系统 |
| 清理与轮换 | 不自动按 retention_days 删除备份或迁移旧副本；账号原位凭据轮换界面后续补齐 |
| 规模与上线 | 当前搜索使用数据库查询，未做万条媒体压测；公网 HTTPS、数据库最小权限、长期任务运行和全浏览器兼容须继续验收 |

## 下一轮验收顺序

1. 在新站添加授权账号，选一个小收藏夹，验证会员画质、多P、评论楼中楼、UP 与头像归档，以及第二次同步的幂等性。

3. 把备份仓库挂到独立设备，执行空环境恢复演练，记录 RPO / RTO。
4. 补充数据规模与公网部署验收，再决定原生云备份、HLS / CDN、历史回滚等下一阶段优先级。
