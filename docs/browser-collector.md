# 浏览器选片助手

选片助手是随 Treasure Up 一起提供的油猴脚本。在 B 站视频页、搜索结果、收藏夹或 UP 主投稿页勾选视频，再统一提交到自己的后端。采集、账号权限检查和下载都由 Docker 服务执行，浏览器提交后可以关闭。

安装排查与新版使用步骤见 [选片助手使用指南](userscript-guide.md)。

## 安装和连接

1. 浏览器安装 [Tampermonkey 官方扩展](https://www.tampermonkey.net/)，使用 5.0 或更新版本。若扩展提示需要开启用户脚本权限，按其官方说明操作。
2. 登录 Treasure Up 管理后台，打开「浏览器采集」，点击「安装选片助手」。脚本文件位于本站 `/userscripts/treasure-up.user.js`；在 Tampermonkey 的安装页检查脚本后安装。
3. 在同一后台页面创建专用令牌，选择已有的 B 站采集账号、有效期和采集选项。令牌仅在创建成功时显示一次，复制后妥善保存。
4. 打开 B 站页面，在「Treasure Up · 选片」面板的连接设置中填写 Treasure Up 的站点地址，点击「验证并保存连接」，在浏览器原生对话框中粘贴令牌，再测试连接。令牌不输入 B 站网页中的文本框。地址使用浏览器实际能够访问的地址；手机或另一台电脑不能用 `localhost` 代替服务器的局域网地址。

公网连接使用 HTTPS；本机和明确的私网 IP 支持 HTTP。输入 `/api/v1` 后缀时会自动归一到站点地址，不支持任意子目录部署。脚本不会跟随 API 重定向，地址应直接指向最终服务，不能填写会跳转到登录页或另一域名的地址。

如果浏览器打开了源码而不是安装页，确认 Tampermonkey 已启用；也可以在其「添加新脚本」中粘贴本站提供的完整脚本内容并保存。脚本由自己的服务提供，不自动从外部站点下载更新；服务升级后可重新打开安装入口更新。

## 选片和采集

- 开启选择后，支持的视频卡片会出现独立勾选按钮，正常的视频链接仍可以打开。视频页可直接添加当前稿件。
- 面板内可移除已选视频，也可以粘贴从其他地方复制的 B 站视频链接或 BV 号。不会抓取任意网站的视频流。
- 一批最多提交 50 个不同的视频。收藏夹或投稿列表滚动加载出的新卡片会继续被识别；不会自动翻页、扫描整个收藏夹或替用户勾选未浏览的内容。
- 待选草稿在当前标签页导航、刷新后保留；不同标签页各自独立，关闭标签页后不再保留。连接设置由油猴私有存储保存。
- 提交后显示逐条结果：已加入队列、正在处理、已有归档、需要后台处理、已删除而禁止重新采集。重复提交不会重复创建同一视频的活动任务。
- 完整进度和失败原因在本站「任务中心」查看。插件显示「已加入队列」不代表视频已下载完成。

播放权限取决于创建令牌时绑定的后台采集账号。充电或会员视频仍需要该账号已有权限；脚本不读取 B 站 Cookie，也不会改变源站收藏、关注或点赞。

## 权限与撤销

专用令牌只允许验证连接和提交 BV 号，不具有浏览器登录会话、查看凭据、编辑视频、删除归档或管理存储的权限。服务端只保存令牌摘要；脚本使用 Tampermonkey 私有存储，不写入 B 站网页的 localStorage。

管理员可以在「浏览器采集」撤销令牌。过期、绑定的本站管理员被禁用或降级、采集账号不可用时，提交会被拒绝。恢复数据库备份时会撤销恢复出来的集成令牌，需要重新创建。

更换服务地址需要重新填写令牌，避免把原服务的令牌发送到另一台服务器。默认有单批、每分钟提交次数和每日新增任务限制；触发限制时保留待选列表，按页面提示稍后重试。已成功入队的任务由后台独立管理，撤销令牌不会撤销此前明确提交的任务。

## 实现与验证

脚本没有外部 JavaScript 依赖，界面与页面样式隔离；运行时确认 Tampermonkey 使用隔离 DOM 沙箱，环境不符合时不读取令牌或联网。跨域请求使用 [Tampermonkey 的 GM.xmlHttpRequest](https://www.tampermonkey.net/documentation.php#api:GM_xmlhttpRequest)，仅向设置中的服务发送 Bearer 令牌与 BV 号；不开放网站全局 CORS，也不携带浏览器 Cookie。

API 为 `GET /api/v1/integrations/userscript/status` 和 `POST /api/v1/integrations/userscript/videos`；后者只接受 `{ "bvids": ["BV…"] }`。采集账号与策略在后台绑定，脚本不能指定任意 URL、任务类型或覆盖服务端策略。

自动验证包含链接解析、动态选片逻辑、请求目标约束、重复提交、令牌过期/撤销及服务端授权隔离。真实浏览器页面结构或扩展权限策略变化时，需重新验证相应浏览器；本地模拟页面的通过不等于所有油猴管理器都兼容。
