# B站选片助手：安装、连接与排查

选片助手运行在普通浏览器的 B站网页里，把选中的 BV 号提交给自己的 Treasure Up 服务。下载由服务器完成；不会读取浏览器里的 B站 Cookie。它需要 **Tampermonkey 5.0 或更新版本**，不支持 App 内嵌浏览器或其他脚本管理器。

## 安装与连接

1. 安装 [Tampermonkey 官方扩展](https://www.tampermonkey.net/)。在扩展管理面板确认它已启用并允许访问 B站。
2. 登录视频库后台，打开「浏览器采集」，点击「安装选片助手」。在 Tampermonkey 安装页检查名称「Treasure Up · B站选片助手」并安装。服务升级后可从同一入口更新；本次脚本版本为 `1.2.0`，面板底部也会显示版本。若安装链接只显示源码，点后台的「复制完整脚本」，在 Tampermonkey「添加新脚本」中替换默认内容并保存。
3. 在后台创建专用采集令牌，绑定已有的来源账号。明文只显示一次；令牌只允许验证连接和提交 BV 号，不能代替后台登录。
4. 刷新 B站网页，点击右下角 **Treasure Up · 选片** → 连接设置。填写视频库站点根地址，再点「验证并保存连接」，在浏览器原生对话框中粘贴令牌。取消对话框不会修改连接；相同地址留空可保留原令牌。验证失败也会保留原有连接。
5. 视频页可以直接点击「加入当前视频」。搜索、收藏或 UP 主视频列表中，打开面板后点击「开启页面选片」，再点视频卡片左上角的 `+`。一批最多 50 个，重复 BV 会自动去重。选中后点击「提交」，在视频库「任务中心」查看下载进度。

地址必须是当前浏览器能直接访问的服务地址。`localhost` 指浏览器所在设备，另一台电脑或手机应填写服务器的局域网 IP 或 HTTPS 域名。公网地址必须使用 HTTPS；不支持反向代理子路径、登录跳转或无效证书。令牌输入在原生对话框中完成，不粘贴到 B站网页的普通文本框，也不需要填写后台密码或 B站 Cookie。

## 按现象排查

| 现象 | 检查方法 |
| --- | --- |
| B站完全没有入口 | 确认扩展及脚本均启用、扩展可访问 B站，然后刷新页面。Chrome 138+ 需要在扩展详情开启「允许用户脚本」；旧版 Chrome、没有该开关的 Edge 按官方指引检查开发者模式。后台网页无法读取你的扩展权限，不能自动判断是否安装成功。 |
| 安装链接只打开源码 | 先启用 Tampermonkey 再重开链接；也可在其「添加新脚本」中粘贴本站提供的完整脚本并保存。不要只复制脚本中的部分函数。 |
| 有入口，却没有卡片勾选 | 在面板中开启页面选片；脚本不会默认拦截 B站原有卡片操作。「选择可见视频」只选择当前视口中的 BV 视频。直播、番剧、短链接应先打开普通 BV 视频页，或粘贴完整链接。 |
| 提示沙箱或权限不完整 | 先更新 Tampermonkey，再从后台重新安装脚本。若提示 DOM 隔离，在 Tampermonkey「设置 → 安全 → 沙盒模式」允许 DOM 后刷新 B站。保留 `@sandbox DOM` 和脚本自带权限，不要改为页面沙箱；不符合隔离要求时脚本拒绝读取令牌或联网。 |
| 标签存储暂不可用 | 不影响当前页选片、连接和提交。未提交的选择暂存在当前页内存，刷新或离开页面会清空。升级扩展并重新安装脚本以恢复标签内跨页保留。 |
| HTTP 401 | 令牌可能无效、过期、撤销，或所属管理员已失效。在后台确认后创建新令牌，再替换脚本连接。 |
| HTTP 409 | 令牌绑定的采集账号不可用；先在后台「B站账号」更新或验证。 |
| HTTP 404／无效 JSON | 地址可能指向其他网站或旧服务。用视频库根地址，并确认服务包含浏览器采集接口。 |
| 网络失败／超时 | 先在同一浏览器直接打开服务，检查证书、地址、反向代理和扩展跨域访问授权。不要绕过证书警告。提交超时可能已入队，应先看后台任务；重试会复用已有任务。 |
| HTTP 429／当日上限 | 保留已选视频，稍后手动重试，不要连续点击。每分钟最多 10 批，每日最多新增 500 个任务；已经接受的项目不会被撤回。 |
| 提交成功但还没有视频 | 成功表示服务器接受了任务，并不代表下载已经完成。检查后台任务进度和账号权限。 |

当前标签页的已选 BV 和标题通过 Tampermonkey 标签存储保留；关闭标签页后不保证继续保留。标签存储缺失、出错或超过 2.5 秒未响应时，会显示提示并退回当前页内存。已选项不会自动在多个标签页之间合并。连接和令牌仍只保存在 Tampermonkey 私有存储；服务响应、令牌和 Cookie 不会进入选片草稿。

## 1.2.0 修复与验证边界

- 标签草稿不再是启动的硬依赖。兼容经典 `GM_getTab` / `GM_saveTab` 回调接口；部分版本异步 API 返回空值、存储报错或挂起时，仍可使用当前页选片和提交。旧版代码会丢失选择或阻止初始化完成。
- 滚动、布局和候选更新时复用已有勾选按钮，避免按下到松开之间替换节点；点击时再次核对可见卡片的 BV，避免复用节点误提交。
- 旧令牌的采集策略缺少新字段时，连接检查补上默认值，不再返回 HTTP 500。只返回允许公开的五项采集选项。
- 增加「复制完整脚本」手动安装入口、版本显示和可操作的初始化指引。
- 19 项脚本及表单测试、22 项后端接口测试与前端类型检查通过。覆盖旧回调、异步空值、存储拒绝/挂起、勾选节点稳定性、令牌作用域、拒绝重定向、不携带 Cookie、错误脱敏和提交去重。
- 本轮在 Codex 内置浏览器的本地合成页面实际点击验证勾选、401 后保留选择、恢复后成功提交；请求由合成 GM 接口截获，没有真实下载。当前自动化没有可用 Chrome，尚未完成真实 Tampermonkey 的安装及跨域提交验证，不能将合成页面测试视为该项已通过。

用户脚本权限要求见 [Tampermonkey 官方 FAQ Q209](https://www.tampermonkey.net/faq.php#Q209) 和 [Chrome userScripts 文档](https://developer.chrome.com/docs/extensions/reference/api/userScripts)。隔离沙箱及标签存储语义见 [Tampermonkey sandbox](https://www.tampermonkey.net/documentation.php?q=sandbox)、[GM 标签存储 API](https://www.tampermonkey.net/documentation.php?q=GM_tabs)。
