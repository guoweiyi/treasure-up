# 标签、评论与 UP 主采集

视频采集把 B 站原始标签纳入可恢复的元数据阶段，视频下载独立调度。`source_tags` 是源站标签，`manual_tags` 是用户标注，展示用的 `tags` 合并两者并去重。刷新 B 站标签不会覆盖人工标注；标签接口失败也不会清空已有标签。

统计定时更新默认开启，间隔 6 小时，默认同时刷新标签和评论。未指定账号时使用最近验证有效的 B 站账号；没有有效账号时等待账号配置，不降级为匿名采集。已明确关闭的统计设置继续生效。弹幕定时刷新仍独立控制，默认关闭。

评论采集按已观察样本中的点赞排序，默认根评论最多 500 条、楼中楼总共 200 条，每个根评论最多 10 条。源站置顶评论优先进入根评论限额（最多识别 3 条），不另外增加无限库存。库存已满时，新置顶可替换点赞最少的普通评论及其回复、评论版本和素材引用。共享人物、头像和不可变素材不会被误删；累计素材下载预算不因替换而增加。取消置顶会在后续成功获取置顶状态时更新。UP 标识由评论作者与当前稿件 owner 的关系判断，其他视频的 UP 不会被误标。

编辑者与管理员可以从 UP 主页面读取最新投稿、筛选普通或充电视频，再勾选最多 30 个视频触发采集。账号凭据始终留在服务端。服务端在提交时与实际采集时都校验稿件作者和充电属性，充电选项不会绕过 B 站账号原有观看权限。重复操作复用正在运行的任务；管理员已删除并禁止重新导入的内容不会复活。

最新投稿直接使用 B 站按发布时间排序的投稿 API。充电筛选作用于当前源站页，返回的总数与下一页仍对应源站投稿分页；当前页没有匹配项不代表后续页也没有。列表结果缓存 5 分钟，可以手动刷新。未选择的远端投稿不下载封面或头像。

接口（均要求 editor 或 admin，会话写入另要求 CSRF）：

- `GET /api/v1/creators/{id}/capture-options`：可用采集账号与默认选择，不包含凭据。
- `GET /api/v1/creators/{id}/latest?account_id=...&page=1&paid=all|only|exclude&refresh=false`：最新投稿及本地保存状态。
- `POST /api/v1/creators/{id}/capture`：`{account_id, bvids: [...], paid: "exclude"}`，返回入队、复用、筛选跳过数量。
